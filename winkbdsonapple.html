Using Non-English Windows/PC Keyboards With Apple Devices



For various reasons some users prefer to use Windows/PC keyboards with their Apple devices.  Unfortunately Mac and Windows keyboard layouts for languages other than English can be slightly different, so that screen output may not automatically match what is printed on the keys.


To help deal with this problem, Apple provides a number of input sources in its keyboard settings specifically designed to match Windows/PC keyboards.  These include


Arabic PC, British PC, Canada PC, French PC, Finnish Sami PC, Hebrew PC, Norwegian Sami PC, Russian PC, Sami PC, Swedish Sami PC


If you cannot find a built-in input source which matches the keyboard you want to use, the Mac program Ukelele can be used to easily create a custom keyboard layout that will fix that.  For iOS devices there is unfortunately no similar program yet.
