Typing and Translating Haitian Creole (Kreyòl)



For users who need to be able to type Haitian Creole on Apple devices, the normal US English keyboard should be sufficient. This language only uses one diacritic, the grave accent, which is available by doing press and hold on the base letter and choosing the accent you want from the popup menu that appears.


Apple does not yet offer spellcheck for Kreyòl. If you need that on an iphone or ipad, you can get it by installing the MS Swiftkey keyboard app. On a Mac, you can get the necessary files here. Some info on installing is here.


For translation, Google Translate is probably the best place to go.
