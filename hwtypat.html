How To Type @


6


2015 Last modified Oct 30, 2026 12:23 PM

It is not always obvious how to type the vital @ character in different language keyboards. 


Normally you should see @ printed on one of the keys, and pressing that key, or that key plus shift or option, should produce the @ character.   If all three produce something else, then your input source setting does not match your hardware keyboard.  To fix that on a Mac, go to system settings > keyboard > text input > edit > all input sources and use the minus button at the bottom to remove any items on the list that do not correspond to your hardware keyboard language.


If you prefer to use an input source which differs from your hardware keyboard, below is a list of locations for some common layouts.  To find @ on any layout, you can use Keyboard Viewer.


US/British/Dutch:  Shift 2


British PC:  Shift '


German/Austrian:  Option L


German Standard:  Option Q


Swiss German/French:  Option G


French/Belgian:  Key next to 1


French Canadian CSA:  Shift 2


Latin American:  Option Q


Spanish/Portuguese:  Option 2


Brazilian/ABNT:  Shift 2


Italian:  Option ò


Swedish/Finnish: Option 2


Norwegian:  Rightmost key in middle row


Danish:  Option '


Russian:  Option 2


Arabic:  Shift 2


Japanese Kana:  Option Shift ふ
